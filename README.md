# CLIO之卷

SillyTavern 角色卡仓库扩展 —— 把角色卡（PNG / JSON）囤进一个独立的卡库，打标签、写简介备注、绑定聊天存档，并把卡一键送进酒馆游玩。

界面是一个 **375 × 667**（iPhone 8 / SE 比例）的居中浮层面板，底部四个栏目（目前只有「角色卡」有内容）。

## 功能

### 角色卡库

| 功能 | 说明 |
|---|---|
| **导入卡** | 拖拽或选择 `.png` / `.json`，卡本体**原样保存**，一个字节不改 |
| **与酒馆合并** | 酒馆里已有的角色自动出现在列表里；同一张卡只显示一次 |
| **两种视图** | 大图模式（2 列网格）/ 列表模式 |
| **搜索** | 精确（整串）与模糊（空格分词、全部命中） |
| **标签** | 从卡自动同步并拆分；点标签收窄范围，可多选（同时满足）；可手动打标签 |
| **标签管理** | 新建 / 改名 / 改色 / 删除 / **拖拽排序**（顺序就是标签栏的排列顺序） |
| **简介与备注** | 每张卡一句话简介 + 私人备注，失焦自动保存 |
| **推送进酒馆** | 未进酒馆的卡一键导入酒馆角色列表 |
| **收进卡库** | 把「仅酒馆」的角色存一份本地副本 |
| **绑定世界书** | 角色专属世界书单本绑定；全局世界书可多选绑定（同一本可被多张卡绑定，只作标记，不写酒馆） |
| **换封面** | 卡图右侧可上传多张附加封面、循环切换、删除；列表页与详情页同步显示当前封面 |
| **导出卡** | 原样导出成文件，可直接分享或再导入酒馆 |
| **Clio的号角** | 顶栏下方的随机推荐条，磨砂玻璃背景，抽样范围 = 当前筛选结果 |

### 聊天

| 功能 | 说明 |
|---|---|
| **浏览酒馆聊天** | 直接读酒馆里已有的聊天记录（只读，不做副本） |
| **新建存档** | 把某次聊天做成**完整快照**，酒馆里那条删了副本也还在 |
| **存档信息** | 时间、楼层数、备注、绑定的 user 面具（从聊天记录自动读取） |
| **恢复存档** | 把存档导回酒馆，变成一条新聊天 |
| **消息折叠** | user 与角色的消息都默认折叠（超 120 字截断），点击展开全文 |
| **继续游玩** | 每条聊天右侧的「▶ 继续」直接切回酒馆接着聊；聊天底部也有 |
| **新对话** | 在卡上开一段新对话（等价于酒馆的「新聊天」） |
| **导出** | 导出记忆（完整）/ 仅导出 char（去掉你的发言） |
| **收藏到书架** | 每条消息旁的「☆ 收藏」打开收藏弹窗：选书目、写备注、加标签、记录来源角色卡；存过变「★ 已收」 |
| **归档** | 聊天查看页最下方点「归档」会弹出存档弹窗（可写备注），确认后存成完整快照 |

### 世界书

| 功能 | 说明 |
|---|---|
| **浏览** | 列出酒馆里的**全部**世界书，分「全局世界书」与「角色卡世界书」两段显示，不会有书被藏起来找不到 |
| **自动同步** | 进入世界书栏目时，把酒馆里新导入 / 内容改过的世界书自动收进库；库里始终有一份副本 |
| **改归属** | 详情页可切换「全局世界书 / 角色卡世界书」：全局会同步加入酒馆的全局世界书，所有聊天可用且可被多张卡绑定；角色卡只给绑定了它的卡使用 |
| **「通用」标签** | 打上它的世界书**强制留在通用库**，即使被某张卡引用 |
| **看条目** | 展开全部条目：标题、关键词、内容预览、是否常驻/禁用 |
| **收进库** | 存一份副本；也支持推送回酒馆、导出、移出库 |
| **标签与备注** | 按世界书名单独存，**没收进库也能写** |

### user 面具

| 功能 | 说明 |
|---|---|
| **列表** | 列出酒馆里的全部面具，显示头像、名字、描述 |
| **看绑定** | 每个面具显示**它绑定了哪些角色卡**（来自酒馆的 `persona_descriptions[].connections`） |
| **搜索与标签** | 有独立的搜索框与标签库 |
| **生成器** | 可折叠；填关键词让 AI 写描述，或自己写；一键创建新面具 |
| **改提示词** | 描述标题右侧的小铅笔可编辑 AI 生成器的默认提示词，保存后长期生效，可一键恢复内置文案 |
| **反向绑定** | 在角色卡详情里可以给卡指定 user 面具 |

### 书架与录像带

**书架**：V1.1.0 起「摘录」升级为书架。**每个分类是一本书**，旧摘录的「标题」变成书内目录的
「备注」；点书脊进书，扫目录，点一行展开正文、标签、来源角色卡与番外指令。
删书不会丢内容（书里的目录移到第一本书），内置书可以改名、删除。

**划线收藏**：装了「书摘」后，在聊天里划中文字，浮条上会多出「★ 收藏」（星号在上、文字在下）。
收藏弹窗里可以选存进书架还是录像带，备注、标签（可多个）、来源角色卡都是可选的。
**书目是一排小按钮，末尾的 ＋ 可以当场新建书名**；同名书不会重复创建。
没装书摘也能用 —— 聊天存档里的「☆ 收藏」打开同一个弹窗。

**录像带**：书架左上角的切换按钮进入。按标签分行，照片横向晾在绳子上，标签固定在每行右侧。
照片框里直接渲染 HTML（放在 `sandbox="allow-scripts"` 的 iframe 里，和面板隔离）；
点开可以复制番外指令、跳回书架里对应的那一条。详情还能切到「代码」查看源码。
新建时点「捕获当前 HTML」：HTML 取聊天里**已渲染**的最新 char 回复
（若是 ```html 代码块则取块内源码），番外指令取最新一条 user 回复；
捕获时把角色专属与全局正则列出来，**默认全选、可逐条手动取消**，只保存勾选的；
详情里可展开查看已收录的正则。编辑录像带时同样可以改选。
番外指令只存在书架条目上，录像带读写同一段，不会各改各的。

书架与录像带在**每次写盘前都会先读一次磁盘**（未加载时自动加载），
所以「还没进过书架就划线收藏」也不会冲掉已有内容。

## 构建与安装

```bash
# 1. 装依赖（只需一次）
npx --yes pnpm@10 install

# 2. 生成样式（改过任何 .vue 里的 class 或 panel.css 后都必须重跑）
node build-css.mjs

# 3. 构建产物
npx --yes pnpm@10 exec webpack --config webpack.extension.mjs --mode production

# 4. 安装到酒馆
node install-extension.mjs
```

或者直接：

```bash
npm run build && node install-extension.mjs
```

装好后刷新酒馆页面（F5），魔法棒菜单里出现「CLIO之卷」。

### 跑测试

```bash
npm test                      # 235 个单元测试，用 Node 内置 node:test，零依赖
npx --yes pnpm@10 exec tsc --noEmit --allowImportingTsExtensions --skipLibCheck -p tsconfig.json
```

> **类型检查必须单独跑**：webpack 的 `ts-loader` 配置为 `transpileOnly: true`，只转译不检查类型。
> 字段名写错、属性不存在这类错误它一个都不报，构建照样显示成功。

## 数据存在哪

全部在酒馆数据目录的 `data/<用户名>/user/files/` 下，扁平存放：

| 文件 | 内容 |
|---|---|
| `clio_index.json` | 索引：所有卡的列表页数据（名字/作者/简介/备注/标签/锚点） |
| `clio_index.bak.json` | 上一次的索引（每次写入前自动备份） |
| `clio_tags.json` | **角色卡**的标签定义（颜色、排序） |
| `clio_world_tags.json` / `clio_persona_tags.json` | 世界书、面具各自的标签库（三套彼此独立） |
| `clio_worlds.json` | 世界书库索引（含「全局 / 角色卡」归属） |
| `clio_world_notes.json` / `clio_persona_notes.json` | 世界书与面具的标签、备注（按名字/头像存，与收没收进库无关） |
| `clio_shelf.json` | 书架库（书 + 目录条目，含番外指令） |
| `clio_shelf_tags.json` | 书架与录像带共用的标签库 |
| `clio_tapes.json` | 录像带元数据（备注、标签、链接条目、收录正则、正文预览片段） |
| `clio_tape_<id>.html.txt` | 录像带 HTML 正文（后缀是 `.html.txt`，因为酒馆禁止上传 `.html`） |
| `clio_excerpts.json` | **旧摘录库**：只在首次启动时迁移成书架，之后只作备份，不删不写 |
| `clio_card_<id>.png` / `.json` | **卡本体，原始字节** |
| `clio_cover_<id>_<时间戳>.<ext>` | 用户上传的附加封面图（原始卡图不在此列） |
| `clio_meta_<id>.json` | 详情页数据（完整卡字段快照、存档列表） |
| `clio_arc_<arcId>.jsonl` | 聊天存档内容 |

**三层保险**：索引同时写在服务端（权威）、服务端备份、浏览器 localStorage（兜底）。
读取时按 主索引 → 备份 → localStorage 的顺序尝试。

> **为什么索引这么重要**：酒馆没有「列目录」的接口，扩展无法知道 `user/files/` 里有哪些文件。
> 索引是「磁盘上有什么卡」的唯一记录，它一旦丢失，卡本体还在但再也找不回来。

## 踩过的坑（都已处理，供后续维护参考）

| 坑 | 说明 |
|---|---|
| **`useShallowCharacters`** | 酒馆开这个设置时，`/api/characters/all` 返回的顶层**没有 `creator`**（值在 `data.creator` 里），只读顶层会让所有卡的作者静默变空 |
| **multipart 字段名是 `avatar`** | 酒馆的 multer 注册写死了 `.single('avatar')`。表单里叫 `file` 会被直接忽略，接口返回 400 |
| **标签有两种形态** | 真实卡里标签可能是数组，也可能是**一个长字符串**（`"开盖即食，全性向，重口"`），必须按 `，,、/\|` 拆开 |
| **`description` 不是简介** | 实测真实卡的 `description` 全是结构化提示词（`narrative_tone_guidelines:` 之类），生成一句话简介只能取 `creator_notes` |
| **文件名限制** | `/api/files/upload` 只接受 `[a-zA-Z0-9_\-.]`，不能是中文、不能带斜杠 |
| **构建要两步** | 改过 `.vue` 的 class 必须重跑 `build-css.mjs`，否则产物里是旧样式且构建不报错 |
| **缓存** | `install-extension.mjs` 会写 `?ver=<时间戳>`，否则浏览器拿不到新代码 |
| **重开面板栏目是空的** | 面板每次打开都新建 Pinia。栏目标签会持久化，但数据**不会**自动加载 —— 必须在 `onMounted` 里按当前栏目调一次加载，否则「上次停在哪个栏目，这次打开就是空白」 |
| **书架被覆盖** | 空书架天生带三本内置书，不能用 `书.length` 判断「有没有加载过」。所有写入都必须先读磁盘（`_改书架库` 负责），读失败时坚决不写 |
| **内置书诈尸** | 判断内置书靠**固定 id**，不能靠名称 —— 用户改名后按名称找不到，就会把原书补回来 |
| **`.html` 不能上传** | 酒馆的 `UNSAFE_EXTENSIONS` 禁止 `.html` / `.htm`，上传接口返回 400。录像带正文因此存成 `clio_tape_<id>.html.txt` |
| **书摘不能 attachReader** | 面板阅读界面在 iframe 里，书摘的划线监听只认宿主 light DOM。只用 `addSelectionButton` 往浮条上加按钮，按钮由书摘在宿主渲染 |
| **正则要跟着录像带走** | 角色专属正则在 `characters[ch].data.extensions.regex_scripts`，全局在 `extensionSettings.regex`；聊天显示时已经套过它们。捕获取的是渲染后的 DOM，同时把正则本身存进录像带 |
| **番外 HTML 不能塞进面板** | 直接用 `v-html` 会让它的 `<style>` 污染界面、`<script>` 在面板里执行。统一用 `sandbox="allow-scripts"` 的 iframe + `srcdoc`，脚本拿不到面板数据 |
| **TauriTavern 没有 `/api/worldinfo/list`** | 前端重写版只实现了 get / get-batch / edit / delete。直接调会拿到 HTML，表现为 `Unrecognized token '<'`；已改为回退到 `updateWorldInfoList()` + `getWorldInfoNames()` |
| **手机端 / 反向代理子路径** | 写死 `/api/...` 会在 `https://host/st/` 下打到域名根，代理返回 HTML。所有站内地址统一走 `服务地址()`，从 `window.location.href` 推导目录 |
| **HTML 被当 JSON 解析** | 新增 `读JSON响应()`：非 JSON 响应会报出「哪个接口、什么状态码、返回了什么片段」，不再只抛 `Unrecognized token '<'` |

## 已知局限

- **同作者同名卡**（如 `和谐友爱修真界1` / `2`）的指纹会撞车，表现为第二张的状态角标不准。卡本身不会丢（内容哈希不同）。正式的「解除关联」尚未实现。
- 花体字标走 Google Fonts 在线加载，**断网时回落到系统手写体**（Windows 上是 Comic Sans）。
- 世界书自动同步只在**进入「世界书」栏目或打开卡详情**时触发；面板一直停在别的栏目时，酒馆里新导入的书要等下一次进入才出现。
- 两本酒馆世界书内容完全相同时，库里只收一份，另一本会以「仅酒馆」出现（共享同一份内容，不重复占用磁盘）。

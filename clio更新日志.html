同步修复与聊天绑定
V1.1.3 改了什么

本次修复「推卡进酒馆」与「世界书同步」的锚点错位，卡与世界书终于能正确落到酒馆；卡详情的全局正则可以原地启用/禁用，聊天记录也能看到当时用的预设、API 与正则。下面是精简归纳。

新增 / 改版 修复 / 兼容

V1.1.3 同步修复 · 绑定信息 · 正则开关 2026-11-04
🧩 修复：推卡 / 世界书同步
  • 角色卡锚点补 .png：酒馆导入接口返回的 file_name 不带扩展名，V1.1.1 直接当锚点，导致世界书绑定静默失败、封面 404、聊天归档找不到卡。现在统一补全，并在启动时自动修复旧索引。
  • 世界书用真实文件名：酒馆写盘时会删掉 / : * 等非法字符。现在写入后回读列表取真实 file_id，不再出现「酒馆里明明有、插件显示没进酒馆」和重复的「仅酒馆」副本。
  • 绑定改用 file_id：推卡时的角色世界书绑定、全局世界书选择都改用它，绑定真正落进酒馆。
🎛 卡详情：全局正则可增减
  • 「全局正则」每条 chip 都可点按启用 / 禁用，图标与底色即时反映状态。
  • 状态直接写回酒馆的全局正则设置，下一次生成立刻生效；展开分区时会重新读取当前设置。
💬 聊天记录：绑定信息
  • 按顺序展示：绑定的预设 → 绑定的 API → 绑定的世界书 → 聊天专属 → 正则 → 指令与录像带 → Mneme 记忆。
  • 七项全部只读、默认可折叠；折叠栏与卡详情同一套纯文字样式；聊天专属世界书形如「聊天专属：h梦模拟器」。
  • 预设 / API / 正则只在归档那一刻抓快照；旧存档显示「未记录」或「当前设置」，不拿现在的值冒充历史。
📚 世界书：分组切换与 Mneme 排除
  • 全局 / 角色卡切换：搜索框下方最左侧、管理标签的左边新增胶囊切换，同一时间只看一组，交互与书架的「书架 / 录像带」一致。
  • Mneme 记忆书不收录：名字以 Mneme 开头的世界书由 Mneme 管理，不再进书库与世界书列表；历史上误收的条目会在同步时自动从索引摘掉（本地副本文件保留）。
  • 这些记忆书仍然通过聊天记录详情的「Mneme 记忆」分区与对应聊天联动显示。
V1.1.1 世界书导入 · 自动归档 · 本地备份 2026-11-03
📥 世界书与随书正则
  • 加号支持整包导入：能识别角色卡、独立世界书、以及「世界书 + 正则」同文件的世界书包。
  • 正则多位置探测：兼容 data.character_book、顶层 entries、extensions.regex_scripts、顶层 regex_scripts / regex。
  • 确认页预览：显示书名、条目数、随书正则条数；可选是否同时写入酒馆与归属。
  • 世界书详情新增「随书正则」折叠区，可查看查找式、替换式与作用位置。
🗂 卡详情重排
  • 一句话简介只读：显示原作者 creator_notes 首句，不再允许编辑。
  • 分区展示：角色卡世界书、角色卡正则、全局世界书、全局正则、绑定面具。
  • 默认折叠：各分区小标题可点击展开/收起，默认全部收起；小标题旁保留编辑与 ＋ 添加按钮。
  • 点开即详情：世界书、正则、面具 chip 都能打开对应详情；全局世界书可用 ＋ 添加。
  • 面具优先级：单次聊天锁定的面具 > 存档记录 > 卡片默认面具。
🗃 聊天存档与实时归档
  • 自动补齐：打开卡详情时，把酒馆里缺失的聊天自动存成副本，不需要再手动「新建存档」。
  • 备注直接改：存档列表里的备注失焦即保存。
  • 实时归档：监听消息发送/收到/编辑/删除，防抖后更新当前聊天副本。
  • 清单拆分：存档清单存 clio_arcindex_<id>.json，避免每条消息重写整张卡 meta；读写走串行队列。
  • 聊天详情：日期、面具、世界书/正则 tag、书架指令与录像带联动、Mneme 记忆块；底部可继续游玩、导出纯文本 / 仅 char / 完整记录，聊天框固定高度可折叠滚动。
🧠 Mneme（姆姆日记）联动
  • 记忆块：显示 Mneme 世界书名、卷宗数、记忆条数、注入方式、卷宗上限、配置世界书与最近摘要。
  • 一键跳转：「在 Mneme 中打开」切到该聊天并尝试打开 Mneme 面板；找不到按钮会提示手动打开。
  • 顶栏说明：使用指南左侧新增大脑按钮，内含联动说明、仓库地址与本机安装命令。
💾 本地存储库
  • 设置顶部新增「存储库」：选择一个电脑文件夹，把数据额外镜像一份。
  • 可选类别：卡库、世界书、书架与录像带、聊天存档，逐项勾选。
  • 实时镜像：聊天存档在每次实时归档后同步写本地；其它类别可点「立即备份选中类别」。
  • 权限提醒：刷新页面后目录可能变成「需要重新授权」，设置里会提示并可重新授权。
🧩 修复与兼容
  • 世界书同步改串行：原来并发读取 23 本世界书会把页面主线程卡死；现在逐本读取，界面始终可响应。
  • 唯一 id 上限：世界书存储 id 分配加了 1000 次上限，哈希异常时直接报错而不是无限循环。
  • 本地目录手势：目录选择改用面板 iframe 的 window 调用，避免浏览器判定「没有用户手势」。
  • 旧数据兼容：老存档清单自动从 meta 迁移到新文件；老世界书没有随书正则时按空数组处理。
V1.1.0 书架 · 录像带 · 划线收藏 2026-10-23
📚 书架
  • 摘录 → 书架：每个分类是一本书，书的目录就是备注；书脊墙点进书内。
  • 旧数据自动迁移：旧分组变书、旧标题变备注；clio_excerpts.json 保留作备份。
  • 删书不丢内容：书里的目录移到第一本书；内置书可改名、删除。
  • 书目小按钮：收藏/编辑时一排小按钮选书，末尾 ＋ 可当场新建书名。
★ 划线收藏
  • 书摘浮条新增「★ 收藏」：星号在上、文字在下；划中文字即可收藏。
  • 统一收藏弹窗：存书架或录像带；备注、多个标签、来源角色卡均可选。
  • 聊天存档的 ☆ 收藏也走同一弹窗；没装书摘时静默降级。
🎞 录像带
  • 照片晾晒：按标签分行，标签钉在右侧；标签下方 ← → 控制左右滑动。
  • 真实 HTML 渲染：沙盒 iframe 渲染番外；900×1200 固定画布等比缩放，详情按内容高度适配；可切代码。
  • 番外指令共享：存在书架条目上，录像带读写同一段；支持复制、跳转并高亮对应目录。
  • 顶部搜索 + 新建；标签列缩窄到 36px，单行更紧凑。
🔍 捕获与正则
  • 捕获当前 HTML：HTML 取最新一条 char 回复（已渲染 DOM；代码块取源码），番外指令取最新一条 user 回复。
  • 正则一并收录：角色专属 + 全局正则列成小按钮，默认全选，可逐条手动取消；只保存勾选的。
🧩 细节与修复
  • 标签栏可直接新建：标签改成小按钮；末尾 ＋ 新建后立刻出现。
  • 栏目改名：底部「摘录」改为「书架」，旧偏好自动映射；数据文件新增 clio_shelf.json、clio_tapes.json。
  • 录像带正文改用 .html.txt：酒馆禁止上传 .html（会返回 400），内容仍是原样 HTML。
  • 数据安全：书架/录像带读写仍走队列；读失败不写盘；旧文件不删不覆盖。
